# Nanami SmartDesk

**Type:** Personal Embedded / IoT Project  
**Repository:** [lidikun48/Nanami-SmartDesk-BETA.VER](https://github.com/lidikun48/Nanami-SmartDesk-BETA.VER)

## Project Overview

Nanami SmartDesk is a personal smart-desk project combining ESP32-based hardware control with a Raspberry Pi Zero 2 W for automation, monitoring, and multimedia functions.

## Architecture

The project uses:

- **ESP32 controller** for sensors, relays, display, and local hardware control.
- **ESP32 audio controller** for audio-related functions.
- **Raspberry Pi Zero 2 W** as a higher-level logic and multimedia node.
- **MQTT** for communication between devices.

## Example Functions

- Presence sensing.
- Temperature/humidity monitoring.
- OLED status display.
- Relay control for desk devices.
- Desk automation logic.
- Audio integration.
- Web-based monitoring/control.
- OTA support for ESP32 firmware.

## Engineering Areas Demonstrated

- ESP32
- Raspberry Pi / Linux
- MQTT
- Sensor integration
- Relay control
- Embedded networking
- Web interfaces
- Multi-device system integration
