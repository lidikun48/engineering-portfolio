## Selected Engineering Projects

### [SmartBrake Edu](https://github.com/lidikun48/SmartBrake-Edu)
ESP32-based motorcycle braking telemetry prototype developed as a D4 final project. The system reads relative front/rear brake pressure and wheel speed, calculates F:R braking distribution, and presents session data through a local Wi-Fi web dashboard.

[Project summary →](projects/smartbrake-edu.md)

### [Nanami SmartDesk](https://github.com/lidikun48/Nanami-SmartDesk-BETA.VER)
Personal embedded/IoT project integrating ESP32 hardware control and a Raspberry Pi Zero 2 W through MQTT for desk automation, monitoring, and multimedia functions.

[Project summary →](projects/nanami-smartdesk.md)
